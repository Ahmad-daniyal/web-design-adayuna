> Dokumen ini disusun **hanya dari isi Guide Book Lomba Web Design INVENTION 2026**.
> Seluruh ketentuan di bawah diambil apa adanya dari Guide Book, memakai istilah resminya,
> dan tidak ditambah asumsi. Ketentuan yang tidak ada dalam Guide Book ditulis
> **"Tidak disebutkan dalam Guide Book"**.

## 2. Ketentuan Peserta

### Status peserta

- Peserta merupakan **pelajar aktif tingkat SMA/SMK/Sederajat di Indonesia**.
- Peserta harus mengikuti mekanisme pendaftaran resmi.
- Peserta wajib melunasi biaya pendaftaran.

### Jumlah anggota tim

- Tim terdiri dari **maksimal 3 orang**.

### Ketentuan lintas institusi

- Anggota tim **dapat berasal dari institusi yang berbeda**.
- Nama institusi **ketua tim** menjadi identitas resmi kelompok.
- Satu institusi dapat mengirim **lebih dari satu tim**.

### Jumlah tim yang boleh diikuti

- Setiap peserta hanya boleh membentuk **1 tim dalam 1 cabang lomba**.
- Peserta dapat mengikuti **lebih dari satu cabang lomba** jika jenis lombanya berbeda.

### Jumlah karya

- Satu tim hanya boleh mengirimkan **1 karya** pada satu jenis lomba.

### Ketentuan nama tim

- Nama tim maksimal **2 kata atau 25 karakter**.

### Kewajiban mengikuti peraturan panitia

- Peserta **wajib mengikuti seluruh prosedur dan peraturan** INVENTION 2026.

## 3. Ketentuan Karya

### Orisinalitas karya

- Website harus merupakan **karya orisinal** peserta.
- Karya **belum pernah dipublikasikan**.
- Karya **belum pernah digunakan** untuk media komunikasi apa pun.
- Karya **belum pernah menjadi juara** pada perlombaan sejenis.
- Karya yang pernah mengikuti lomba sejenis tetapi tidak menjadi juara **wajib mengalami improvement yang signifikan**.
- **Dilarang menggunakan template website yang sudah ada.**
- Penggunaan template yang sudah ada dapat menyebabkan **diskualifikasi langsung**.

### Larangan template website

- **Dilarang menggunakan template website yang sudah ada.**
- Pelanggaran ini dapat menyebabkan **diskualifikasi langsung**.

### Ketentuan karya yang pernah dilombakan

- Jika karya pernah mengikuti lomba sejenis tetapi tidak menjadi juara, karya **wajib mengalami improvement yang signifikan**.

### Kesesuaian tema dan subtema

- Website **harus sesuai** dengan tema `Innovative Web Solutions for a Smarter Digital Society`.
- Website **harus sesuai** dengan **salah satu** dari 5 subtema yang tersedia.

### Larangan konten

Website **tidak boleh**:

- Mengandung unsur **SARA**.
- Mengandung **pornografi atau pornoaksi**.
- Mengandung **unsur promosi**.
- Mengandung **hal negatif**.
- Melanggar **hukum atau norma yang berlaku di Indonesia**.

### Framework CSS yang diperbolehkan

- **Bootstrap**
- **Tailwind**
- **Framework CSS lainnya**

### Framework/library JavaScript yang dilarang

| Library/Framework | Status |
|---|---|
| jQuery | Diperbolehkan |
| React | **Dilarang** |
| Angular | **Dilarang** |
| Vue | **Dilarang** |
| Framework/library JavaScript lainnya | **Dilarang** (selain jQuery) |

### Penggunaan CDN

- Seluruh framework atau library yang digunakan **wajib menggunakan CDN** (*Content Delivery Network*).

### Jumlah halaman website

- Minimal **1 halaman (page)**.
- Maksimal **7 halaman (page)**.

### Bahasa website

- **Bahasa utama website adalah Bahasa Indonesia.**
- **Istilah dalam Bahasa Inggris diperbolehkan.**

### Static website

- Website **wajib berbentuk static website**.
- Website **disarankan dapat diakses secara online**.

### Hosting

Hosting dapat menggunakan layanan seperti:

- **GitHub Pages**
- **Vercel**
- **Netlify**
- atau layanan hosting gratis sejenis

### Penggunaan aset pihak lain

- Peserta boleh menggunakan **ilustrasi digital**, **fotografi**, dan **aset visual lainnya**.
- Aset milik orang lain **tidak boleh melanggar hak cipta**.
- Aset milik orang lain **wajib memiliki Open License**.

### Pencantuman sumber aset

- **Sumber ilustrasi atau foto wajib dicantumkan** pada deskripsi karya.
- Sumber karya milik orang lain juga **diharapkan dicantumkan sebagai komentar pada source code** yang dikumpulkan.

### Hak cipta dan Open License

- Aset milik orang lain wajib **tidak melanggar hak cipta** dan **memiliki Open License**.

### Hak kepemilikan karya

- Karya **tetap menjadi hak milik peserta**.
- Panitia **berhak mempublikasikan** karya peserta melalui media sosial INVENTION.

## 5. Tahap Penyisihan

Peserta **wajib mengunggah**:

- **Proposal**
- **Mockup**
- **Source code beserta seluruh aset**
- **Link website yang telah di-hosting**

Seluruhnya dikumpulkan melalui **link Google Drive**.

### Ketentuan mockup

| Ketentuan | Nilai |
|---|---|
| Format file | `.jpg` atau `.jpeg` |
| Maksimal tinggi | **1350 px** |
| Maksimal lebar | **1080 px** |

### Ketentuan proposal

| Ketentuan | Nilai |
|---|---|
| Ukuran kertas | **A4** |
| Spasi | **1,5** |
| Font | **Times New Roman** |
| Ukuran font | **12 pt** |
| Margin kiri | **4 cm** |
| Margin atas, kanan, bawah | **3 cm** |
| Format file | `.pdf` |
| Maksimal halaman | **30 halaman** |

### Sistematika proposal

1. Judul/Nama Website
2. Subtema yang Dipilih
3. Nama Tim dan Anggota
4. Kata Pengantar
5. Daftar Isi
6. Latar Belakang
7. Tujuan, Manfaat, dan Solusi yang Ditawarkan
8. Proses Perancangan Desain UI/UX
9. Analisa Kebutuhan
10. Fitur-fitur dalam Website
11. Keunikan Website
12. Teknologi yang Digunakan
13. Hasil Survei dan Uji Coba Pengguna
    - Target Pengguna
    - Pertanyaan dan Hasil
    - Kesimpulan
14. Kesimpulan
15. Daftar Pustaka
16. Lampiran

### Lembar orisinalitas

- **Wajib mengisi** lembar orisinalitas.
- **Wajib ditandatangani secara basah**.
- Menggunakan **materai Rp10.000**.
- **Dilampirkan** pada proposal.
- Dikumpulkan dalam bentuk **hasil scan**.

### Ketentuan survei dan uji coba pengguna

- **Dokumentasi** survei/uji coba pengguna **wajib dilampirkan**.
- Jika dokumentasi berupa video, **dapat menggunakan tautan video**.
- Data survei dan uji coba **wajib berasal dari responden nyata**.
- Data **tidak boleh merupakan hasil generasi AI**.

### Ketentuan source code dan aset

- Source code beserta seluruh aset dikumpulkan dalam bentuk **`.zip`**.

### Ketentuan Google Drive

Dalam satu folder harus terdapat:

- Source code
- Aset karya
- Mockup
- Proposal
- Hasil Turnitin proposal
- Link website

Folder **harus dapat diakses panitia dengan permission View Only**.

### Format nama folder

```text
INV-WDS-NoPeserta
```

> Pola lanjutan nama folder **tidak tercantum lengkap** dalam Guide Book yang tersedia.

**Tidak disebutkan dalam Guide Book.**

### Ketentuan pengiriman ulang

**Tidak disebutkan dalam Guide Book.**

### Tidak adanya perpanjangan waktu

**Tidak disebutkan dalam Guide Book.**

## 10. Larangan dan Risiko Diskualifikasi

### Larangan

**Karya dan konten**

- Larangan menggunakan template website yang sudah ada.
- Larangan memuat konten SARA.
- Larangan memuat pornografi atau pornoaksi.
- Larangan memuat unsur promosi.
- Larangan memuat hal-hal negatif.
- Larangan melanggar hukum atau norma yang berlaku di Indonesia.

**Teknologi**

- Larangan menggunakan React.
- Larangan menggunakan Angular.
- Larangan menggunakan Vue.
- Larangan menggunakan framework/library JavaScript selain jQuery.

**Struktur**

- Larangan melebihi 7 halaman.

**Aset**

- Larangan menggunakan aset yang melanggar hak cipta.
- Larangan menggunakan aset milik orang lain tanpa Open License.
- Larangan tidak mencantumkan sumber ilustrasi/foto pada deskripsi karya.

### Pelanggaran yang secara eksplisit disebut menyebabkan diskualifikasi

| Pelanggaran | Konsekuensi |
|---|---|
| Penggunaan template website yang sudah ada | **Diskualifikasi langsung** |

### Ketentuan yang menjadi tanggung jawab peserta

- Menjamin karya merupakan karya orisinal peserta.
- Menjamin karya belum pernah dipublikasikan.
- Menjamin karya belum pernah digunakan untuk media komunikasi apa pun.
- Menjamin karya belum pernah menjadi juara pada perlombaan sejenis.
- Memastikan karya yang pernah mengikuti lomba sejenis mengalami improvement yang signifikan.
- Memastikan seluruh file wajib tahap penyisihan diunggah (proposal, mockup, source code beserta aset, link website).
- Menjamin proposal sesuai format A4, spasi 1,5, Times New Roman 12 pt, margin 4/3/3/3 cm, `.pdf`, maksimal 30 halaman.
- Mengisi dan menandatangani lembar orisinalitas secara basah dengan materai Rp10.000 lalu melampirkannya dalam bentuk scan.
- Menyediakan data survei dan uji coba pengguna dari responden nyata, bukan hasil generasi AI.
- Melampirkan dokumentasi survei/uji coba pengguna.
- Membungkus source code beserta seluruh aset dalam `.zip`.
- Membuat folder Google Drive dengan permission View Only.
- Menyediakan hasil Turnitin proposal.
- Menulis sumber aset pada deskripsi karya dan komentar source code.
- Mematuhi seluruh prosedur dan peraturan INVENTION 2026.
